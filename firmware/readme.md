# Firmware Binaries
---

This folder contains the pre-compiled firmware for the board. It includes the MCUBoot boot-loader, which is used to manage and run application images. The included firmware provides basic input/output functionality, such as UART and GPIO ports, and also features a simple blinky project to test if the board is working properly.

This binary is for using with serial-boot via UART in case the main boot loader is damaged.
